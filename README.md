# Loan Default Risk Analysis Using SQL and Excel

## Project Overview

In this project, I’m analyzing loan and borrower data for Horizon Financial Group to better understand patterns in loan defaults.

The company issued over 600 personal loans across 2024 and 2025, and approximately 1 in 4 loans are defaulting. Since the company’s target default rate is 12%, the goal is to explore the data and identify borrower and loan characteristics that may be related to higher default rates.

I’m using SQL and Excel to analyze the data, compare default rates, and present findings that could help support lending decisions.

## Business Questions

* How do default rates differ across credit score ranges?
* Which loan purposes have the highest default rates?
* How do employment status and years employed relate to default risk?
* Are borrowers with less than two years of employment more likely to default?

## Tools Used

* **MySQL:** Querying and analyzing loan data, joining tables, grouping records, and calculating default rates.
* **Microsoft Excel:** Reviewing analysis results and creating charts to compare default rates and identify patterns.

## Datasets

This project uses two datasets:

* **Borrower Profiles:** Contains borrower information, including income, credit score, and employment details.
* **Loan Applications:** Contains loan information, including loan amount, loan term, interest rate, loan purpose, and repayment status.

I use these datasets together to explore how borrower characteristics and loan details relate to loan defaults.

## Analysis Process

1. **Query the data using SQL** to explore loan records and combine borrower information with loan details.
2. **Calculate default rates** to compare outcomes across credit score ranges, loan purposes, and employment groups.
3. **Review the results in Excel** to organize findings and create visualizations.
4. **Look for patterns** that may help explain which groups have higher default rates.
